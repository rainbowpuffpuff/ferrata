== 15. What the contract does not expose ===================================================================
  - Registered tokens: no enumeration getter. Listed from TokenRegistered events (and native ETH probed with tokenConfig(0x0)).
  - Pending candidates: a mapping keyed by newState. Listed from CandidateSubmitted events, each read with candidates(newState).
  - Whether a pending candidate is live: needs the internal counter _stateChanges (epoch = revocationEpoch + _stateChanges); read from storage slot 52, shown only if the three public getters sharing that slot match.
  - Relay fees: tokenConfig() does not return them; shown from fees(token, index, d) (the schedule's copy) and TokenRegistered.
  - The registry entry's lezDefinition and decimals: only in RegistryEntryPublished events and, hashed, at the entry slot.
  - Fee schedules' fromLeaf, announcedAt and effectiveAt: no getter; from FeesInForce and FeesAnnounced events (the fees themselves from fees()).
  - Release-delay history: no getter for the list; releaseDelayFor(token, i) per checkpoint and ReleaseDelaySet events.
  - Proposed watchers: roleProposal() omits the array; from the last RolesProposed event.
  - Cap buckets' stored level and last update: only `available` (tokenCap/globalCap); utilisation = capacity - available.
  - Payees owed and depositors: no enumeration; from OwedCredited/OwedClaimed and Deposit events, then owed()/depositCount().
  - The linked FerrataRegistry library: no getter; found as a PUSH20 constant of the vault's code that has code itself.
  - Who holds the admin, freeze-authority and watcher keys (or that a key holder exists): not on chain; only whether each address has code.
  - The stop's circuit-breaker rule (estop with a receipt of the zero claim): from RISC Zero's source; the chain shows paused() and owner().
  - Which deposit a claim on LEZ used, which burn a release spends, the burns behind a burn root: on LEZ or hidden by design, not on Ethereum.
  - Rule (A) _lastBeaconBlock: internal (slot 44), shown for rule (A) vaults only.

Every program on this network, with the image id a documented rebuild reproduces from its source commit, checked live against the loader header on chain; and every app this host serves, checked file by file against the repository.

Programs

On LEZ a program is named by its image id, the hash of its exact RISC Zero binary. The loader keeps the id in the program account's header; an immutable header can never point at another binary. So a program is what its source builds to, if the build is reproducible: ours are (scripts/guest-rustc makes guest builds independent of the machine and path; docs/image-ids.md shows two builds at two paths giving equal bytes).

Apps on this host

Each app is a set of static files; each file's SHA-256 is in the site manifest, tied to a commit of the repository; the manifest marks which of those commits are public. The "Files" column is checked live: this browser fetches every file of the app and compares its hash with the manifest (a convenience: for a check that holds against this host, run python3 -I scripts/site-manifest.py verify; see Verify).

The Ferrata bridge on this test network

A private bridge for ETH and ERC-20 tokens between Ethereum (here Sepolia) and LEZ: deposits are public on Ethereum, the LEZ account they pay is not; burns on LEZ release on Ethereum against a zero-knowledge proof.

Test network, test value only. Not audited.

Use it

Deposits start in the wallet (any EIP-1193 browser wallet on Sepolia). Claims, burns and releases need a proof made on your own machine with the ferrata tool from the repository; see why.

Vault: 0x19499061CeC0BaC2a3E1869Ba5AE6B403aA82787 on Sepolia. LEZ bridge program: ferrata_bridge_b1.

This page is static and its source is in the public repository: deploy/testnet/web/trust/. Every file this host serves is listed with its SHA-256 and commit in the site manifest; check it from a clone with python3 -I scripts/site-manifest.py verify. No cookies, no analytics, no third-party scripts.

against it and checks the journal) equals index.tsv's; each private run's `program image` line is its
program's. Every id is a row of the first table of [`docs/image-ids.md`](../../docs/image-ids.md), this tree's
guests; where the stage's SHA256SUMS is kept, the guest binary's sha256 equals that row's.

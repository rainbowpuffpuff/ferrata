Generated by `python3 -I bench/perf/summarize_proofs.py bench/perf/results/p2-a` from the logs of `perf_prove --prove`
(`lez/harness/src/bin/perf_prove.rs`), run by `bench/perf/prove_modal.py` (one container per transition) or
`bench/perf/prove-actions.sh` (one machine). **Measured.** Each row is one guest execution of the attestation
program (or the reference consumer) with the exact input LEZ v0.4.0-rc1 gives it in the transaction named,
proven for real by `r0vm` (`RISC0_DEV_MODE=0`): a composite receipt (one per segment), verified against
the image id with its journal compared to the executor's, then compressed to one succinct receipt, verified
again. LEZ v0.4 does not prove public transactions (every node re-executes them); these are the proofs a
prover of the same execution would make, RFP-020's method ("RISC0 proof time, RISC0 proof size"). Peak
memory is the whole process's (`/usr/bin/time -v`, maximum resident set of `r0vm`, which proves).
